# Portfolio of Web Projects

This repository is a personal collection of front-end practice projects built with HTML and CSS. It represents my learning journey in web development and showcases a variety of mini-projects focused on layout, design, visual structure, and content presentation.

## Overview

The main goal of this portfolio is to present my work as a beginner developer in a clear and organized way. Each page in this project explores a different concept, theme, or design challenge, allowing me to practice important web development skills such as:

- semantic HTML structure
- responsive page layouts
- section-based content design
- multimedia embedding
- forms and interactive elements
- portfolio presentation and project organization

## Project purpose

This repository acts as a digital portfolio and a showcase of practical exercises. Rather than being a single application, it is a set of independent pages that share the same overall style and purpose: demonstrating my progress, creativity, and ability to build functional web pages.

## Included pages

- `index.html`: landing page and main entry point
- `portfolio.html`: personal portfolio page with project summaries and profile information
- `developer-form.html`: survey form focused on learning habits and developer goals
- `media-player.html`: page showcasing audio and video playback in HTML
- `event-hub.html`: football events hub with upcoming and past tournaments
- `spiderman-page.html`: Spider-Man history and cultural content page
- `comic-catalog.html`: catalog of notable Spider-Man comics
- `spiderman-rating.html`: movie review page for "Spider-Man: Brand New Day"

## Technologies used

- HTML5
- CSS3
- Static page design
- Responsive layout concepts

## Learning focus

These projects helped me practice and improve:

- building structured and readable page layouts
- organizing content with cards, sections, lists, and tables
- presenting information visually in a clean and appealing way
- developing multiple themes using the same core front-end skills
- creating a portfolio that can be shared and used as a personal digital resume

## Final note

This repository is a personal growth project and a reflection of my early web development journey. It brings together several small but meaningful creations that demonstrate both my technical learning and my creative interests.
